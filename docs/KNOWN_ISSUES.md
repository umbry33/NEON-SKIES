- 用户已确认当前 GitHub 部署版本在手机和电脑上均可正常运行。
- 项目采用轻量冒烟标准：正式修改后，至少在一台手机和一台电脑打开部署版本，检查启动、改装、战斗、暂停/恢复和配置码流程。
