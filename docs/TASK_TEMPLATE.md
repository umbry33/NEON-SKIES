# 任务模板

复制本文件后填写；没有相关项写“不适用”，不能留空造成误解。

复杂任务是指涉及多个系统、存档/兼容、玩家可见玩法，或预计需要三类以上文件和手动回归的任务。复制后的任务记录应放在任务约定的位置；若项目没有单独任务目录，则至少在交接文档中保留结论，不要把聊天记录作为唯一状态。
