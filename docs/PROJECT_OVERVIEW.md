# 项目概览

## 定位

Neon Skies 是一款竖屏、霓虹蒸汽波风格的 Canvas 纵向射击游戏。核心差异是“先装配、后战斗”：玩家不是只选择一架固定飞机，而是在 15×15 的核心连接网络上摆放模块，让空间占位、模块组合、连携能力和主动技能共同决定战斗方式。

## 设计目标

- 让模块摆放本身成为可理解、可分享、可扩展的构筑系统。
- 用数据驱动关卡、敌人、环境、模块和随机航程，减少新增内容对主循环的侵入。
- 桌面和触摸输入共享同一套 Pointer Events 交互，保持移动端可玩性。
- 使用 Canvas 几何绘制和 Web Audio 合成，保持项目可直接运行且不依赖外部资源。
- 让普通关卡、躲避模式和光锥之外提供不同的节奏，而不是只重复同一战斗。

## 核心玩法与游戏循环

1. 主菜单进入模式、百科、更新日志或改装界面。
2. 在固定核心周围放置自动模块和技能模块；系统检查边界、重叠和核心连通性。
3. 保存当前机体并进入战斗；自动模块按攻速开火，玩家移动并释放主动技能。
4. `Game` 更新敌机、敌方弹幕、玩家弹幕、碰撞、伤害、分数、环境和 HUD。
5. 普通关卡达到目标分后结束，Boss 关还必须击败 Boss；其它模式按各自条件结算。
6. 光锥之外在节点之间前进，获得模块、金币、生命和事件结果，最终完成章节或因失败结束。

## 主要系统

- 机体装配：15×15 网格、任意平移、多单元 footprint、连通性、快捷装配、撤销、删除和配置码。
- 战斗：自动射击、主动技能、敌机移动/射击、Boss、敌方弹幕、碰撞、伤害反馈和暂停。
- 模式：无尽、100 关卡、躲避弹幕、新手教程、光锥之外。
- 内容：26 个标准装配界面可见模块、合成/禁用模块定义、4 个连携能力、100 关、20 个标准 Boss 关、9 类环境配置、34 个深空事件。
- 辅助：游戏百科、更新日志、设置、音量调节、伤害跳字、震动开关和攻速规则说明。

## 视觉与音效

- 视觉方向：深蓝背景、青/紫/粉霓虹、蒸汽波落日、透视网格、扫描线、半透明玻璃面板。
- 飞机、敌机、模块图标、子弹和技能效果使用 Canvas 2D 几何图形；绘制入口集中在 `src/rendering/ModuleRenderer.js` 与实体/场景渲染器中。
- 背景音乐和战斗音效由 `src/systems/SoundSystem.js` 使用 Web Audio API 合成，音量可在设置中调节 0%–300%。

## 目标平台与未确认项

- 已有桌面和触摸事件路径，目标是现代桌面/移动浏览器。
- 具体浏览器最低版本、横屏策略、屏幕阅读器支持和性能基线尚未形成正式矩阵，标记为“待确认”。
- 当前不包含联网、账号、排行榜、数据库、故事流程或本地自动存档。
