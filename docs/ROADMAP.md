# Roadmap

本文件只区分当前事实和未来意图，不把建议写成承诺。

## 已完成（代码已实现）

- v0.7.0 的模块与战斗机制已进入当前 Git 基线：天幕协议、黑曜波束、幽蓝奇点、星蚀脉冲、星环、火羽和暗蚀连携。
- 关卡模式已扩展到 100 关，包含后期敌机、Boss 变体和特殊环境。
- 光锥之外已具备多章节航程、路线、事件、奖励、库存、合成数据和航程码。
- 躲避弹幕、教程、百科、设置、动态音效和 15×15 装配已存在。
- 发布目录与 ZIP 已依据当前源码重新生成并完成内容抽查。

## 当前开发中（已存在但未完成闭环）

- 光锥之外模块合成：系统、配方和 UI 面板存在，但 `src/ui/BeyondLightConeUI.js` 当前删除合成入口；已确认不作为正式开放功能。

## 下一步（计划，需任务确认）

1. 依据“不正式开放”决定是否进一步收敛合成 UI 的死代码和文案，但不要把合成系统开放给玩家。
2. 建立最低浏览器与性能基线。

## 长期计划（来源于原 DEVELOPMENT.md，尚未承诺）

- 模块旋转与更清晰的 footprint 预览。
- 可编写的敌人波次、Boss 模式和关卡奖励。
- 模块掉落、战斗内替换、更多敌机行为。
- 模块升级、稀有度成长、装备限制和多个本地机体保存槽。
- 更多声音、粒子和可选外部艺术资源。

## 暂缓/未实现

故事、联网、账号、排行榜、数据库、自动本地存档和多人功能没有当前实现；除非用户明确提出，不应在一般开发任务中顺手引入。
