# Roadmap

本文件只区分当前事实和未来意图，不把建议写成承诺。

## 已完成（代码已实现）

- v0.7.0 的模块与战斗机制已进入当前 Git 基线：天幕协议、黑曜波束、幽蓝奇点、星蚀脉冲、星环、火羽和暗蚀连携。
- 关卡模式已扩展到 100 关，包含后期敌机、Boss 变体和特殊环境。
- 光锥之外已具备多章节航程、路线、事件、奖励、库存、合成数据和航程码。
- 躲避弹幕、教程、百科、设置、动态音效和 15×15 装配已存在。

## 当前开发中（已存在但未完成闭环）

- 测试基线同步：`tests/logic-tests.js` 仍包含按 50 关、旧百科结构、旧模块数量和旧合成奖励策略编写的断言；需要决定修复测试还是回退产品规则。
- 光锥之外模块合成：系统、配方和 UI 面板存在，但 `src/ui/BeyondLightConeUI.js` 当前删除合成入口；是否在下一版本开放待确认。
- 发布包同步：源码在 v0.7.0，忽略的发布目录/ZIP 可能早于当前源码，正式发布前需重新生成并验证。

## 下一步（计划，需任务确认）

1. 逐项处理测试断言与 v0.7.0 当前行为的差异，先确认产品规则，再同步测试。
2. 决定光锥之外合成系统是否开放；若开放，补齐库存、配方、分解、奖励和移动端流程验收；若不开放，收敛死入口和文案。
3. 修正 34 个深空事件在 UI/百科中仍显示为 30 个的玩家可见文案。
4. 重新生成发布包，检查全量资源、入口、移动端和部署流程。
5. 建立最低浏览器与性能基线。

## 长期计划（来源于原 DEVELOPMENT.md，尚未承诺）

- 模块旋转与更清晰的 footprint 预览。
- 可编写的敌人波次、Boss 模式和关卡奖励。
- 模块掉落、战斗内替换、更多敌机行为。
- 模块升级、稀有度成长、装备限制和多个本地机体保存槽。
- 更多声音、粒子和可选外部艺术资源。

## 暂缓/未实现

故事、联网、账号、排行榜、数据库、自动本地存档和多人功能没有当前实现；除非用户明确提出，不应在一般开发任务中顺手引入。
