# 测试结果记录

本文件是项目实际测试结果的统一记录空间。测试清单定义“要测什么”，本文件记录“何时、对哪个版本、用什么环境、实际测到了什么”。

## 记录规则

- 每次代码、配置、资源、测试基线或正式发布验证后新增一条记录，不覆盖历史结果。
- 必须注明日期（Asia/Shanghai）、版本或 commit；未提交工作区必须明确写“工作区未提交”。
- 必须区分代码回归、测试断言过期、测试夹具问题和环境限制。
- 手机端回归必须记录真实设备或移动端模拟环境、浏览器和实际操作结果。
- `AI_HANDOFF.md` 只引用最近记录，不把历史结果默认视为当前工作区结果。

## 记录模板

### YYYY-MM-DD｜版本/commit/工作区状态

- **范围：**
- **环境：** 桌面设备/系统/浏览器；手机或模拟器/系统/浏览器
- **命令：**
  - `node --check ...`
  - `powershell -ExecutionPolicy Bypass -File .\start-server.ps1`
  - 逻辑测试页面：`http://localhost:5500/tests/index.html`
- **自动检查：** 测试数量、PASS/FAIL、静态检查和 HTTP 结果
- **手动流程：** 启动、改装、战斗、暂停/恢复、配置码、触摸拖动、技能按钮及本次任务专项流程
- **控制台：** 错误、警告或“无新增错误/警告”
- **发布目录：** 未生成、FolderOnly 已检查或完整发布包已检查
- **结果：**
- **失败分类/环境限制：** 无则写“不适用”
- **后续处理：**
