- 浏览器本地存档只在当前浏览器设备和站点来源内有效；清理网站数据或更换设备后，普通机体需用配置码迁移，光锥之外航程需用航程码迁移；当前没有云端同步。
- `CHANGELOG.md` 有项目级确认规则，修改前必须先列完整候选条目并等待用户确认。
- UI 有动态注入元素，不能只检查 `index.html` 静态 ID；要同时检查 `UI.js` 和 `BeyondLightConeUI.js`。
