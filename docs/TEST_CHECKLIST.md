# 测试检查清单

## 新版本规则断言

- [ ] 以当前代码和已确认决策为准更新断言，不沿用旧版本数量：当前主线为 100 个关卡、每 5 关一个 Boss、34 个光锥之外事件。
- [ ] “光锥之外模块合成系统不正式开放”属于产品边界：合成定义可以保留供内部维护，但禁用模块不得进入玩家装配库、奖励池或可见入口；UI 入口需人工确认不可见。
- [ ] 打开 `http://localhost:5500/tests/index.html` 后，结果必须显示 `All tests passed`；任何 FAIL 都必须先判断是代码回归、过期断言还是测试夹具缺失。
- [ ] 测试夹具必须初始化被调用方法所需的状态数组、对象和边界，不能把“夹具未准备好”误判为玩法 Bug。

## 启动与静态检查

- [ ] `git status --short` 已确认范围。
- [ ] 使用 `powershell -ExecutionPolicy Bypass -File .\start-server.ps1` 启动成功。
- [ ] 主页面 `http://localhost:5500/` 加载，无模块导入错误。
- [ ] 浏览器控制台没有新增 error/warn。
- [ ] 本次涉及的 JS 通过 `node --check`。
- [ ] `tests/index.html` 已运行并记录 PASS/FAIL；旧失败必须与 `KNOWN_ISSUES.md` 对照。

## 轻量兼容冒烟

- [ ] 当前 GitHub 部署版本在一台电脑上能打开并完成一次启动、改装、战斗、暂停/恢复。
- [ ] 当前 GitHub 部署版本在一台手机上能完成同样流程，并检查触摸拖动和技能按钮。
- [ ] 发现卡顿、崩溃、冻结或布局问题时，记录设备、浏览器、页面地址和复现步骤；没有问题时不额外建立性能报告。

## 桌面操作

- [ ] 主菜单、更多菜单、设置、百科、更新日志可打开/关闭。
- [ ] 模式选择可进入无尽、100 关卡、躲避、教程和光锥之外。
- [ ] 改装界面可拖入模块、显示 footprint 预览、阻止重叠/越界、清理断开模块。
- [ ] 快捷装配、撤销、删除、模块详情、攻速规则和连携配置可用。
- [ ] 普通模式改装界面可打开机库，显示 10 个槽位；存储机体、应用机体、切换槽位和刷新后恢复均正常。
- [ ] 点击已保存机体名称可编辑；回车或失焦保存，手机端点击后能调出系统键盘，刷新后名称仍保留。
- [ ] 机体名称包含数字时可正常保存；每个机库槽位的“配置码”按钮可复制或导入，导入配置码后目标槽位可应用且结构正确。
- [ ] 光锥之外改装界面不显示机库；未完成航程可在入口继续本地航程。
- [ ] 普通配置码可以复制、导入、校验错误并恢复机体。
- [ ] 普通战斗自动开火、敌机生成、碰撞、伤害、分数、技能和结算正常。
- [ ] 暂停后可继续；返回主菜单/路线图会出现二次确认。

## 键盘、鼠标、触摸

- [ ] WASD 和方向键移动，边界不会越界。
- [ ] 数字键 1–9 释放对应技能，冷却显示正确。
- [ ] 鼠标拖动装配模块和画布移动均不触发误点击。
- [ ] 触摸拖动飞机、触摸技能按钮、双指/指针手势不造成重复点击。
- [ ] 移动端模块仓库滚动、连携按钮、弹窗和删除区不越界。

## 各模式

- [ ] 无尽模式持续生成敌人并可结束。
- [ ] 关卡 1、普通关、Boss 关、26 关后环境、51 关后敌池分别抽查。
- [ ] 躲避模式三种难度生成不同密度/速度弹幕，躲过弹幕可计分。
- [ ] 教程按移动、技能、800 分条件推进，不能跳过必要步骤造成死锁。
- [ ] 光锥之外新航程、路线、战斗、商店、回复、事件、章节、奖励和失败流程可走通。
- [ ] 光锥之外存档码复制/导入后地图、库存、生命、金币、机体和进度一致。
- [ ] 清理站点数据或更换设备后的迁移路径明确：普通机体使用配置码，光锥之外航程使用航程码；本地存档不应被误认为云端备份。

## 新旧功能与兼容

- [ ] 旧模块 ID、share code、机体配置码仍可解析。

## 性能与发布

- [ ] 菜单和战斗切换时动画在页面隐藏后停止/恢复正常。
- [ ] 大量模块、敌人、弹幕和特效下无明显卡死或无限增长。
- [ ] 桌面和至少一台手机检查布局；本项目暂不维护独立浏览器矩阵和固定性能预算。
- [ ] 源码修改后运行 `package-release.ps1 -FolderOnly` 重新生成发布目录。
- [ ] 发布目录包含最新 `index.html`、`styles.css`、`src/`、`assets/`，不上传半套文件。
