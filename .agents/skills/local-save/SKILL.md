# 本地保存

仅在当前项目根目录执行。此 Skill 只创建本地 Git 提交，不触发 GitHub 或其他线上操作。

## 流程

1. 运行 `git status --short`。没有变更时直接说明“没有需要提交的内容”，停止。
2. 检查待提交文件，避免暂存密码、Token、密钥、`.env`、本地配置或其他敏感内容。发现疑似敏感文件时停止并说明文件名，等待用户处理。
3. 阅读变更摘要，生成一条简洁准确的中文提交说明，例如“新增：Boss 召唤敌机”或“修复：移动端按钮触控”。
4. 根据改动运行必要检查。优先使用项目现有的测试或静态检查；检查失败时停止，不提交。
5. 默认不修改 `CHANGELOG.md`。只有用户明确要求时才更新它。
6. 只暂存本次需要保存的项目文件，执行 `git add` 和 `git commit`。
7. 严禁执行 `git push` 或任何线上发布操作。
8. 完成后报告提交说明、commit hash 和 `git status --short` 的结果。

## 安全规则

- 不执行 `git reset`、`git rebase`、`git clean`、`git stash pop`、强制 push 或任何改写 Git 历史的操作。
- 不删除文件。
- 提交前再次确认暂存区内容与用户当前改动一致。
